# Repo About Draft

## Short Description

Privacy-first macOS per-app volume control without microphone permission or audio-input capture.

## About

VolDeck is a privacy-first macOS menu bar app for controlling volume and mute per app. It is designed around an output-only audio pipeline, so it should not require microphone permission, should not trigger the orange mic indicator, and should not use audio-input capture.

The project starts as a personal-use tool, with a path toward a polished product later. The core principles are local-first behavior, no analytics by default, no telemetry by default, and clean-room implementation.
